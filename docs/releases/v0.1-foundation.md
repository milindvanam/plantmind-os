# PlantMind OS v0.1-foundation

Release date: 5 August 2026
Status: Sprint 1 approved and complete

## Summary

`v0.1-foundation` establishes the approved PlantMind OS prototype baseline: a single Next.js/TypeScript modular monolith, PostgreSQL persistence, a premium industrial design system, six primary route foundations, and a deterministic P-204A degradation replay.

## Included

- Responsive shared application shell with dark and light themes
- Exactly six approved product routes
- Accessible shared component foundation and semantic state treatments
- Fifteen-table PostgreSQL schema with migration support
- Deterministic fixture with seven sensors, 679 readings, 97 operating metrics, six stages, and two maintenance records
- Start, pause, resume, restart, reset, stage-jump, and replay-speed controls
- Browser-local continuity and validated PostgreSQL replay snapshots with audit events
- Loading, empty, error, disabled, simulated, evidence, confidence, and audit states
- Unit, integration, end-to-end, type, lint, formatting, build, and dependency-audit verification

## Verification at release

- Formatting, ESLint, TypeScript, and production build passed
- 10 unit/component tests passed
- PostgreSQL fixture integration test passed
- 10 Playwright browser tests passed
- Production dependency audit reported zero vulnerabilities

## Deliberately excluded

No model integration, AI-generated briefs, anomaly/root-cause logic, impact calculation, approval workflow, CMMS integration, live connector, microservice, queue, cache, vector database, knowledge graph, or digital twin is included.

## Governing documents

The founding architecture blueprint, CTO review, prototype product and engineering blueprint, and archived Sprint 1 implementation report remain the governing references for subsequent work.
